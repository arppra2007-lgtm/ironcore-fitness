# 🏋️ IRONCORE FITNESS

### Premium Gym & Fitness Website

A modern, responsive gym website designed and developed by **PixelCraft Studio** using HTML, CSS, and JavaScript.

This project showcases a professional fitness business website with a bold dark theme, neon green accents, interactive elements, and a mobile-friendly layout.

> **Note:** This is a portfolio demonstration project. Business details, pricing, trainers, and contact information are sample content.

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

No additional installation is required.
